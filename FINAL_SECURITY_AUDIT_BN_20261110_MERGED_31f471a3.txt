## সংশোধিত/একত্রিত বিষয়
1. Storage `uploads` INSERT/UPDATE/DELETE policy-তে Admin role check.
2. Private `premium-pdfs` bucket এবং Admin-only object write/read policies.
3. Paid PDF public URL-এর বদলে private object path সংরক্ষণ এবং signed URL endpoint.
4. Premium PDF endpoint-এ user authentication, approved unlock request, paid-post state ও publication checks.
5. Chatbot-এ client-provided `system` role গ্রহণ বন্ধ.
6. Admin auth state resolve শেষ না হওয়া পর্যন্ত loading state ধরে রাখা.
7. Unpublished parent post-এর chapter table read restriction.
8. IP extraction-এ `X-Forwarded-For`-এর প্রথম caller-controlled hop-এর বদলে final hop ব্যবহার.
9. Admin unlock counter-এর table name `pdf_unlock_requests` করা.
10. PDF processing-এ OpenAI-compatible image endpoint-এ PDF পাঠানো বন্ধ; PDF path direct Gemini fallback-এর native `inline_data`-তে রূপান্তরিত হয়.
11. Supabase placeholder config-এর পরিবর্তে explicit configuration validation.
12. Paid PDF metadata stale হয়ে থাকা ঠেকাতে trigger hardening.
